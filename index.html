Instalar MESA CERO

Android con Chrome:

  1. Abre la dirección publicada de MESA CERO en Chrome.
  2. Presiona el menú ⋮ de Chrome.
  3. Elige Instalar aplicación o Agregar a la pantalla principal.
  4. Confirma. El ícono M0 aparecerá entre tus aplicaciones.

Si Chrome ofrece instalación automática, usa el botón «Instalar en celular». Requiere haber publicado en una dirección HTTPS como GitHub Pages. En un archivo HTML abierto desde Descargas no funciona la instalación.
